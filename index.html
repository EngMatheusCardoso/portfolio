02

Casos reais

SQL SERVER · ERRO 945

Instância que não subia

O ERRORLOG mostrou o master de template apontando os bancos de sistema para um caminho inexistente. Subi em modo mínimo com -T3608, corrigi com MODIFY FILE e recriei o acesso sysadmin.

ERP · ERRO 26

Servidor que resolvia para IP público

Com NetBIOS desligado, o roteador mandava um sufixo DNS que respondia qualquer nome. Achei o servidor consultando a porta UDP 1434 de cada IP e corrigi a resolução de nomes.

NF-E · PATTERN

Nota rejeitada só nos itens com lote

O Registro MS estava vazio nos produtos com lote. Corrigi os dados no SQL Server, retransmiti a nota e criei a orientação para evitar novos casos.

LINUX · LVM

Disco em 100% sem downtime

Expandi o VHDX no Hyper-V e propaguei pelo LVM (pvresize, lvextend, resize2fs) com o servidor ligado: o uso caiu de 100% para 46%.

POWERSHELL · AMSI

Falso positivo do Defender

O script foi bloqueado como malicioso. Removi os padrões de "código gerando código" e o console voltou a abrir sem precisar de exclusões.

VPN · CGNAT

Registro separado do túnel

O SSH era inalcançável por causa do CGNAT. Passei o registro dos peers para HTTPS 443 e um timer no servidor aplica as mudanças. O túnel sobe sozinho.
