# portfolio

Código do meu portfólio: **[portfolio.mysolucoesemti.com.br](https://portfolio.mysolucoesemti.com.br)**

- `index.html` — página única, sem framework, nas cores da M.Y (HTML + CSS puro)
- `og.jpg` — capa 1200×630 para prévia no LinkedIn e WhatsApp
- `worker/worker.js` — Cloudflare Worker que serve os arquivos deste repositório no domínio próprio, com cache na borda

**Deploy:** um `git push` na `main` publica em até 5 minutos, sem build e sem servidor.
